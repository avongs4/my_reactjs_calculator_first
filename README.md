# Welcome to My Reactjs Calculator
***

## Task
The goal of this project is to build a simple, interactive calculator using ReactJS. The challenge lies in implementing a clean, single-page application (SPA) that performs all basic arithmetic operations (+, -, *, /) dynamically, while handling multiple operations in a single input and maintaining a responsive UI.

## Description
This project was developed using ReactJS as a single-route application. The core logic of the calculator was implemented in a Calculator.js component. Additional reusable components (like buttons and display) were placed under the src/components/ directory, each styled with its own CSS file. The app handles dynamic expressions, displays results in real-time, and includes a clear/reset function. It is fully responsive and styled with custom CSS.

The project was deployed to the cloud using AWS Amplify and can be accessed at:

🔗 https://dev.d1g3ueyxit0kwr.amplifyapp.com

## Installation
Clone the repository and install the dependencies:
git clone <https://git.us.qwasar.io/my_reactjs_calculator_182294_6cx-dy/my_reactjs_calculator.git>
cd my-reactjs-calculator
npm install

## Usage
To run the app locally:
npm start

To build the app for production:
npm run build

This project is a browser-based web app. After starting the server, open your browser and go to:
http://localhost:3000

Once deployed, the app is accessible at:
https://dev.d1g3ueyxit0kwr.amplifyapp.com
